# codmso scoop bucket

Scoop bucket for [codmso](https://github.com/codmso)'s apps.

## How to use

```powershell
scoop bucket add codmso https://github.com/codmso/scoop-bucket
scoop install oiia-cat-desktop-pet
```

## Apps

| App | Description |
| --- | --- |
| [oiia-cat-desktop-pet](https://github.com/codmso/oiia-cat-desktop-pet) | A 3D desktop cat (Oiia) that lives on your screen and spins to your typing. |

## Updating

To update an app:

```powershell
scoop update oiia-cat-desktop-pet
```
